# 閱畢測驗

為指定文章設計加強記憶與複習的 **4～5 題 QA**：其中 **1～2 題為較難的綜合題**，串聯至少兩個觀念，要求推理或情境判斷；其餘各釐清一個重點概念。使用者另有要求時，以該次要求為準。

## 出題方針

先讀完整篇文章，選出最值得記住的要點，避免重複設問或只考日期、代碼等枝節：

1. **辨清核心概念**：針對容易混淆的觀念，要求用自己的話解釋，避免只背名詞。
2. **運用情境判斷**：用簡單數字或市場案例，練習計算、比較，並交代判斷所需的假設。
3. **檢驗因果與反例**：追問證據、其他可能解釋及不成立的條件，避免把相關性或單次經驗當成投資定律。

答案以文章內容為依據，簡短說明理由；計算保留算式、單位與假設，區分已確認事實與情境估算。綜合題的難度來自觀念連結，不靠冗長敘述或冷僻知識。

## 放置與更新

- 放在文章頂部，保留 frontmatter、import 與資料日期；已有測驗時更新原區塊，避免重複。
- 同一個 tip 內放入 4～5 組 details，依序編號，每題預設收合。使用以下格式：

```mdx
:::tip[閱畢測驗 TEST！]

<details>
<summary>Q1：...</summary>

**A**：...

</details>

:::
```

## 格式與確認

- 粗體末尾的標點放在 `**` 外，例如 `**重點**：`、`**完整句子**。`，不要寫成 `**重點：**` 或 `**完整句子。**`。
- 確認題數、編號、每題答案與標籤完整；確認沒有重複測驗區塊，且內容在文章中有依據。
- 使用專案現有的 MDX 解析或編譯工具檢查語法；若只調整測驗且已通過相關檢查，不必為此新增測試程式或重做不相關檢查。
- 完成後簡述題數、位置及檢查結果，提供文章連結。
